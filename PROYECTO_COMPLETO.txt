   1. Guía Completa - Resumen, conceptos, ejemplos, procedimientos, preguntas

🚀 CÓMO USAR
================================================================================

OPCIÓN 1 - ABRIR DIRECTAMENTE (MÁS FÁCIL):
  1. Abre index.html en tu navegador
  2. ¡Listo! Verás 2 guías de ejemplo

OPCIÓN 2 - CON SERVIDOR NODE.JS:
  1. npm install
  2. npm start
  3. Ve a http://localhost:3000

CONFIGURAR CLAVE API:
  1. Ve a https://console.anthropic.com/
  2. Crea clave API (gratis con $5 de prueba)
  3. En Guía10: Haz clic en ⚙️ Configuración
  4. Pega tu clave y guarda
